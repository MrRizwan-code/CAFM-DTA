# Release overview

This GitHub repository contains source code, compact results, figure-generation inputs and exports.
Large datasets, graph caches, predictions and checkpoints are archived on Zenodo; see DATA_AND_ARCHIVE_README.md.

Verified source-backed revisions: row-aligned export, restored simple_concat,
eight existing-checkpoint evaluations (KRAS OFF/FiLM seed 1; DS2 OFF/FiLM seeds 1–3),
corrected Figures 6/S2, and explicit Figure 4 checkpoint provenance. No new seed or experiment is implied by this release.

Known gap: the IC50-only control reported in the manuscript comes from an earlier run whose original
checkpoint, predictions and log were not recovered (see KNOWN_LIMITATIONS.md).
The manuscript and Supporting Information are provided through the journal submission.
